# fastCutVid 0.1.4

This release keeps the timeline anchored under your mouse during trackpad zoom, improves media preview sizing and loading, and plays macOS cuts through one native timeline.

## Changes

- Trackpad pinch zoom keeps the time beneath the cursor in place until a timeline boundary is reached, including when the timeline is already scrolled.
- Preview and filmstrip frames preserve source display proportions for portrait, square, rotated, and non-square-pixel media.
- Filmstrip frames and waveform sections appear progressively. Background decoding uses a bounded worker pool, cancels obsolete work when switching projects, and limits texture uploads to keep editing responsive.
- Cached media analysis is reused across sessions. Changed sources and damaged cache entries are rebuilt, and old cache entries are pruned toward 256 MiB.
- Timeline drawing is limited to the visible area, including filmstrip cells and waveform samples.
- macOS playback uses one native composition and shared clock across cuts, including clip mute and volume settings.
- Development now uses Git Flow, protected branches, and CI on Linux, macOS, and Windows. Release checks require final version tags on `main`; the Rust compiler is pinned for consistent checks and builds.
- Regression tests cover cursor anchoring, media shapes, progressive loading, caching, playback across cuts, and release policy. Rotated-media fixtures support older FFmpeg versions.

Existing `.fastcut`, `.fastcut.json`, and `.json` projects remain compatible. The `fastcut.timeline/v1` format is unchanged.

## Downloads and installation

Choose a platform archive under **Assets**:

- Apple silicon, macOS 12+: `fastcutvid-v0.1.4-macos-arm64.tar.gz`
- Intel Mac, macOS 12+: `fastcutvid-v0.1.4-macos-x86_64.tar.gz`
- Windows x86-64: `fastcutvid-v0.1.4-windows-x86_64.zip`
- Linux x86-64, Ubuntu 22.04+ or compatible: `fastcutvid-v0.1.4-linux-x86_64.tar.gz`

Each archive includes a SHA-256 checksum file, documentation, and the timeline skill. Save your work and quit the old app before replacing it.

**macOS:** Extract the archive, move `fastCutVid.app` to Applications, and launch it once to register `.fastcut` files with Finder.

**Windows:** Extract into a permanent folder and run `powershell -ExecutionPolicy Bypass -File .\register-file-type.ps1` there.

**Linux:** Extract into a permanent folder and run `python3 register-file-type.py` there. Registration requires `update-mime-database`, `update-desktop-database`, and `xdg-mime`.

FFmpeg and FFprobe must be installed separately and available on `PATH`, or configured with `FASTCUT_FFMPEG` and `FASTCUT_FFPROBE`.

## Known limitations

- Windows/Linux interactive preview remains silent; macOS preview and MP4 exports include audio.
- macOS packages are ad-hoc signed, not Apple-notarized; Windows packages are unsigned.
- There is no undo/redo, autosave, or automatic media relinking. Projects reference their source media without embedding it.
