# fastCutVid 0.1.3

Projects now have their own **`.fastcut`** extension, so they can be opened directly in fastCutVid. The contents remain `fastcut.timeline/v1` JSON.

## Changes

- Save As and Export cuts default to `.fastcut`. Cut exports use names such as `Interview-cutted.fastcut`.
- Existing `.fastcut.json` and `.json` projects still open. Saving an existing project preserves its path; use Save As to create a `.fastcut` copy, or rename the original file without moving it away from its media.
- macOS registers the project type with Finder. Double-clicking a project opens it at launch or in the already-running app, including paths with spaces and Unicode characters.
- Windows and Linux packages include per-user file-association scripts.
- Open dialogs, drag-and-drop, command-line routing, and agent/operator documentation support the new extension. Ordinary JSON files keep their existing operating-system associations.

## Downloads and installation

Choose a platform archive under **Assets**, not GitHub's source archives:

- Apple silicon, macOS 12+: `fastcutvid-v0.1.3-macos-arm64.tar.gz`
- Intel Mac, macOS 12+: `fastcutvid-v0.1.3-macos-x86_64.tar.gz`
- Windows x86-64: `fastcutvid-v0.1.3-windows-x86_64.zip`
- Linux x86-64, Ubuntu 22.04+ or compatible: `fastcutvid-v0.1.3-linux-x86_64.tar.gz`

Each archive includes a SHA-256 checksum file, documentation, and the timeline skill. Save your work and quit the old app before replacing it.

**macOS:** Extract the archive, move `fastCutVid.app` to Applications, and launch it once. Then double-click `.fastcut` files in Finder.

**Windows:** Extract the archive into a permanent folder and run `powershell -ExecutionPolicy Bypass -File .\register-file-type.ps1` there. If Windows asks, select fastCutVid in **Open with**.

**Linux:** Extract the archive into a permanent folder and run `python3 register-file-type.py` there. Registration requires `update-mime-database`, `update-desktop-database`, and `xdg-mime`. Rerun Windows/Linux registration if you move the release folder.

FFmpeg and FFprobe must be installed separately and available on `PATH`, or configured with `FASTCUT_FFMPEG` and `FASTCUT_FFPROBE`.

## Known limitations

- macOS provides synchronized video/audio preview. Windows/Linux interactive preview remains silent; MP4 exports include audio.
- macOS packages are ad-hoc signed, not Apple-notarized; Windows packages are unsigned.
- No undo/redo, autosave, or automatic media relinking. Save before closing or replacing a project. Projects reference media without embedding it.
- Export can overwrite its destination. Never use a source-media path as output.
